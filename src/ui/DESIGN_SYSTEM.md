# 02｜设计系统与移动端规则

## 颜色

所有颜色通过语义令牌使用，不允许业务组件自行增加近似色。

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `canvas` | `#F6F8FC` | 应用背景 |
| `surface` | `#FFFFFF` | 内容表面 |
| `ink` | `#17223B` | 标题、正文、主按钮 |
| `ink-soft` | `#5F6B82` | 次要说明 |
| `ink-faint` | `#8F99AC` | 非关键标签；不用于小号正文 |
| `line` | `#E2E7F0` | 边界、分隔、骨架 |
| `indigo` | `#4C55D7` | 主操作、当前项、可交互进度 |
| `indigo-strong` | `#343DB8` | 强调文字与按下态 |
| `indigo-soft` | `#ECEEFF` | 选中背景 |
| `mint` | `#258467` | 已完成、可用 |
| `mint-soft` | `#E3F4ED` | 完成背景 |
| `coral` | `#E87963` | 录音、需注意状态 |
| `coral-soft` | `#FFF0EC` | 注意背景 |
| `danger` | `#C84444` | 明确错误与破坏性警告 |
| `danger-soft` | `#FFF0F0` | 错误背景 |

规则：

- `coral` 和 `ink-faint` 不单独承载小号正文；搭配图标时仍需 `ink` 文本。
- 设备故障使用 `coral` 或中性色，不能使用“答错”的 `danger` 语义。
- 专项不固定绑定不同主色，以免颜色被误解为能力等级；图标色只帮助快速识别。
- 深色主按钮统一使用 `ink`，主操作不在同屏切换多种颜色。

## 字体

不加载远程字体，保证离线和隐私边界。

| 角色 | 字体栈 | 用法 |
| --- | --- | --- |
| 展示 | Avenir Next、SF Pro Rounded、PingFang SC | 页面标题、关键数字、英文学习对象 |
| 正文 | PingFang SC、SF Pro Text、系统无衬线 | 中文导航、说明、反馈 |
| 工具 | SF Mono、系统等宽 | 极短眉题、顺序编号、时间 |

字号基线：

- 页面标题：`28–35px`，行高 `1.1–1.2`
- 区块标题：`20–22px`，行高 `1.25`
- 卡片标题：`16–18px`，行高 `1.35`
- 正文：`15–16px`，行高 `1.6`
- 辅助信息：`12–13px`，行高 `1.5`
- 极短眉题：`11px`；不能承载必要说明

中英文混排不强制全大写。全大写只用于不影响理解的短英文眉题。

## 间距、圆角和阴影

间距使用 `4px` 基线：

`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48`

- 页面水平边距：常规 iPhone `20px`，320px 宽度下降为 `16px`。
- 区块垂直间距：`32–40px`。
- 卡片内边距：`16–24px`。
- 标签与正文：`4–8px`。
- 控件之间：最低 `8px`，避免误触。

圆角：

- 小标签：`999px`
- 图标容器：`14–17px`
- 按钮：`16–18px`
- 卡片：`20–24px`
- 关键计划面板：`26px`

阴影只表达层级：

- 普通卡片优先使用 `1px` 边界，无阴影或极弱阴影。
- 固定底部导航使用向上阴影。
- 关键主面板可以使用一层强调阴影。
- 禁止所有卡片同时漂浮，避免通用仪表盘外观。

## 图标

- 使用 24px 线性图标，默认线宽 `1.8`。
- 小控件可降到 18–20px，大录音按钮可提高到 28–32px。
- 图标必须跟随文本语义，不能单独表达错误、权限或录音结果。
- 同一动作始终使用同一图标；播放、暂停、停止不能混用。

## 组件状态

所有交互组件至少覆盖：

1. 默认
2. 按下
3. 键盘焦点
4. 禁用
5. 加载
6. 已完成
7. 错误

主按钮：

- 每屏最多一个。
- 高度最低 `54px`。
- 加载时保持宽高，替换内部内容，不允许页面跳动。
- 禁用必须有文字原因或邻近说明，不能只降低透明度。

选择项：

- 整行可点击，最低高度 `52px`。
- 选中使用边框、背景和图标三重反馈。
- 正确/错误反馈必须同时出现文字，不只用绿/红。

音频与录音：

- 播放、暂停、录音、停止均为明确按钮，不依赖长按或隐藏手势。
- 录音中必须持续显示“正在录音”和已用时间。
- 识别处理中不能锁死返回和回放。
- 降级为回放时必须说明“本次未评分”，不能出现负面学习反馈。

## iPhone 竖屏与单手操作

- 最小设计宽度 `320px`，主要验证宽度 `390px`。
- 内容最大宽度 `480px`，桌面只作为居中预览，不重新设计桌面导航。
- 使用 `env(safe-area-inset-*)` 处理刘海、圆角和主屏幕模式。
- 底部导航视觉高度 `72px`，另加底部安全区。
- 滚动内容底部留出导航和主按钮空间，禁止内容被固定导航遮挡。
- 高频操作位于屏幕下半部；退出、帮助和低频设置可以放在顶部。
- 训练主操作可以使用底部吸附操作区，但不能同时保留底部导航。
- 不使用仅靠左右滑动才能发现的关键功能。
- 系统键盘出现时，输入框和提交按钮必须仍可滚动到可见区域。

## 无障碍

- 触控目标至少 `44 × 44px`。
- 正文和交互文字达到 WCAG AA 对比度；装饰色不能承担必要信息。
- 每页一个 `h1`，标题层级不跳级。
- 当前导航使用 `aria-current="page"`。
- 加载和异步结果使用适度的 `aria-live`，避免每秒计时反复播报。
- 进度使用 `progressbar` 语义并提供文字值。
- 录音、播放和权限状态提供可读名称。
- 焦点轮廓宽度 `3px`，不能被圆角容器裁切。
- 支持 `prefers-reduced-motion: reduce`。
- 文字放大到 200% 时允许纵向增长，不允许横向滚动或截断必要内容。

## 动效

- 按钮与选择项反馈：`120–180ms`。
- 页面内状态切换：`180–240ms`。
- 进度变化：最多 `360ms`。
- 只为“状态已改变”服务，不使用持续漂浮、随机粒子或循环呼吸。
- 录音中的必要状态可以使用低频脉冲，但减少动态时必须停用。
- 页面切换不依赖动画表达方向，动画关闭后信息关系仍然成立。

## 文案

- 按钮使用动作结果：“继续今日计划”“允许麦克风”“播放录音”。
- 错误说明必须回答“发生了什么”和“现在能做什么”。
- 不使用“糟糕”“很遗憾”等情绪化填充。
- 不把设备、网络、权限或内容故障写成用户答错。
- `unknown`、低置信度和非官方 CEFR 声明必须忠实保留。
