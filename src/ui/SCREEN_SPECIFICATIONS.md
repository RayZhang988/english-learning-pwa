# 02｜主要页面规格

## 共同页面骨架

```text
┌──────────────────────────────┐
│ 安全区                        │
│ 页面标题 / 当前阶段            │
│ 页面说明或进度                 │
│                              │
│ 主要内容                      │
│                              │
│ 单一主行动                    │
│ 底部安全区 / 导航或专注操作区   │
└──────────────────────────────┘
```

- 应用壳页面显示三项底部导航。
- 水平测试和专项训练使用专注模式，不显示底部导航。
- 专注训练页只保留一个视觉优先级最高的主行动；自由选择页允许多个同级真实入口。
- 页面组件只接收 ViewModel 和回调，不加载数据、不注册路由、不调用设备 API。

## 今天

### 页面任务

让用户在 3 秒内看清计划状态，并从所有未完成任务中自由选择一项开始。

```text
日期                         连续学习
问候

┌ 今日计划 ───────────────────┐
│ 45 分钟                      │
│ 已完成 1 / 3                 │
│ ━━━━━━━━━━━                  │
└─────────────────────────────┘

任选一项开始
┌ 词汇复习      开始训练 ┐
├ 听力训练  建议先做  继续训练 ┤
└ 口语跟读      开始训练 ┘
```

### 输入

- `DailyPlan`
  - `status`
  - `targetSeconds`
  - `plannedSeconds`
  - `unfilledSeconds`
  - `tasks`
  - `warnings`
- `PlanProgress`
  - `status`
  - 每个 `TaskExecutionState.status`
  - `spentSeconds`
- `PlanTaskAccess`
  - `tasks[].taskId`
  - `tasks[].targetModuleId`
  - `tasks[].taskStatus`
  - `tasks[].availability`
  - `tasks[].recommended`
  - `tasks[].unavailableReason`
- `ProgressSnapshot.streak`

### 显示规则

- 词汇、听力、口语任务使用同级选择卡，不显示序号、前后连线或固定顺序暗示。
- 时间只格式化，不重新分配。
- `partial` 必须展示未排满提示及业务警告。
- `empty` 不显示虚假的 0% 计划卡。
- `blocked` 与 `skipped` 不使用完成勾选。
- 连续学习只展示 `streak.currentDays`，不根据日历自行计算。
- `DailyTaskViewModel.taskId` 原样承载 `LearningTask.taskId`；页面不得改写成模块 ID。
- `availability === "startable"` 的三个任务必须同时可点击；`recommended` 只增加
  “建议先做”徽标、边框和读屏说明。
- 已完成、已跳过、计划外或数据异常任务使用原生禁用按钮；状态与不可执行原因均来自
  外部 ViewModel 并进入可访问名称。
- 任一可点击任务行触发 `onTaskRequested(taskId)`；UI 不决定目标路由，不读取
  `nextTaskId`，也不根据数组位置推导权限。

## 水平测试

### 测试说明

```text
关闭                    水平测试

找到适合你的起点
约 15–20 分钟，分别估算：

Aa 词汇       ◖ 听力       ● 口语

结果只作为学习起点参考，不是官方认证。

[检查设备并开始]
```

输入：

- 预计时长文案
- 三个专项说明
- `AbilityProfile.disclaimer` 对应的预先说明
- 音频和麦克风准备状态

### 选择题

```text
词汇                  当前阶段进度
━━━━━━━━━━━━

题目要求
题干 / 刺激内容

○ 选项 A
○ 选项 B
● 选项 C
○ 选项 D

[提交答案]
[跳过本题] [暂停测试]
```

输入：

- 原始 `sessionId` 与 `item.id`
- `AssessmentPhase`
- `PublicChoiceAssessmentItem.prompt`
- `stimulus.text`
- `stimulus.audioText`
- `stimulus.maxPlays`
- `options`
- 外部提供的选中项、主行动、跳过和暂停状态

反馈态的主行动必须明确变为“继续下一题”并触发 `onContinue`，不能继续显示“提交答案”
或复用 `onSubmit`。`onSkip` 仅在外部提供可用 `skipAction` 时可触发。

UI 绝不能接触 `scoring.correctOptionId`。

### 口语题

```text
口语                  当前阶段进度
━━━━━━━━━━━━

朗读 / 跟读 / 回答
业务模块提供的提示

[仅跟读题：示例音频 · 播放/暂停 · 播放次数]

       ◉
   点击开始录音

录音中：00:08 / 识别中 / 可回放

[提交本题]
[跳过本题] [暂停测试]
```

输入：

- 原始 `sessionId` 与 `item.id`
- `PublicSpeechAssessmentItem.prompt`
- `stimulus.text`
- `stimulus.audioText`
- `stimulus.maxPlays`
- 仅跟读题提供的 `AssessmentSpeechAudioViewModel`
- 外部提供的录音/识别/回放状态
- 外部提供的 `lastSubmission` 展示模型和 fallback 文案

示例音频播放器只在 `audio` 存在且集成层提供 `onToggleAudio` 时显示；点击后原样回传
`sessionId` / `itemId`。UI 不朗读 `audioText`、不限制播放次数，也不把示例播放与录音
回放合并成同一动作。

识别失败、录音失败、权限拒绝与离线均按 `unscorable` 展示，不使用答错视觉。反馈态
同样通过 `onContinue` 继续，不复用语音提交动作。

### 暂停

```text
关闭                    水平测试

            暂停
        准备好后继续

离开期间不计入测试时间；恢复后回到运行时保存的状态。

[继续测试]
[结束并保留部分结果]
```

输入：

- 原始 `sessionId`
- 外部提供的暂停说明
- `actions.canResume` 映射后的恢复行动
- `actions.canStop` 映射后的结束行动

UI 只触发 `onResume(sessionId)` 或 `onStop(sessionId)`，不推断恢复到题目还是反馈，也
不提供 03 runtime 不存在的“重新开始”动作。

### 结果

```text
本次起点估算

词汇  B1      置信度：高
听力  A2–B1   置信度：中
口语  暂无结果

每项独立说明、区间和警告

非官方 CEFR 免责声明
[生成今日计划]
```

输入：

- `AbilityProfile.outcome`
- 三项 `AbilityEstimate`
- `disclaimer`

`unavailable` 显示“暂无可靠结果”，不能显示 0、pre-A1 或复制其他专项。

## 词汇训练

### 页面任务

让词、释义、例句和作答控件保持清晰层级；不在同屏暴露所有解释。

```text
关闭        词汇 · 复习        3 / 8
━━━━━━━━━━━━

选择最合适的含义

check in
/ˌtʃek ˈɪn/       动词短语

○ 办理入住
○ 查看里面
○ 支付账单

[确认]
```

答后反馈：

```text
正确 / 需要再看一次
英文例句
中文解释
[下一题]
```

### ViewModel 最低字段

- 任务标题、模式、进度文字和进度值
- 题目要求
- 学习对象、词性和可选辅助信息
- 选项及外部提供的状态
- 外部提供的反馈标题、说明、例句和解释
- 主行动标签和回调

02 不定义题型、答案、音标来源、标准化得分或何时进入反馈。

## 听力训练

### 页面任务

首听时聚焦音频和问题；翻译只能在业务模块允许的答后阶段出现。

```text
关闭        听力 · 新学        2 / 6
━━━━━━━━━━━━

听一遍，然后回答

┌─────────────────────────────┐
│          ▶                  │
│ 00:12  ━━━━━━━━  00:28      │
│ 速度 1.0×       已播放 1/2   │
└─────────────────────────────┘

播放设置
[0.75×] [1×] [1.25×]
播放片段 [第 1 句 ▾]
重复方式 [不重复] [当前句] [全文]

问题
○ 选项 A
○ 选项 B
○ 选项 C

[确认]
```

答后可追加：

- 原文逐句
- 中文解释
- `rationaleZh`

关键词听写题把选项区替换为：

```text
输入你听到的关键词
┌─────────────────────────────┐
│ 输入英文关键词              │
└─────────────────────────────┘
输入状态说明
```

### ViewModel 与回调最低字段

- 播放状态：待播放、播放中、暂停、结束、不可用、错误
- 已播时间、总时长、进度值
- 当前速度数值与可选速度数值/标签
- 稳定片段 ID、当前片段 ID、片段标签和禁用状态
- 重复模式：`none`、`segment`、`all`
- 题目使用判别联合：
  - `single-choice` 只提供问题和选项
  - `keyword-dictation` 只提供问题、输入值、占位、禁用和提交视觉状态
- 答后反馈、带稳定 ID 的原文和解释
- 回调：播放切换、速度变化、片段变化、重复变化、题目输入、主行动和退出

速度与重复使用原生单选语义，片段使用原生选择框；所有控件支持键盘和 VoiceOver，
触控目标不低于 44px。320px 宽度允许选项换行，文本输入使用至少 16px 字号并可随页面
滚动。关键词听写的主行动随输入区排列，不使用会覆盖输入框的固定底栏；单选题仍使用
底部固定主行动。

UI 不合成音频、不计播放次数、不验证片段、不判定答案、不决定提交状态或翻译何时可见。

## 口语训练

### 页面任务

把“要说什么、设备正在做什么、失败后还能做什么”同时讲清楚。

```text
关闭        口语 · 跟读        1 / 4
━━━━━━━━━━━━

跟读这句话
英文目标句
中文任务提示

           ◉
       点击开始录音

麦克风状态说明
[开始录音]
```

录音中：

```text
           ■
       正在录音 00:08
[停止录音]
```

识别失败但录音可用：

```text
本次无法识别，因此不会评分。
▶ 播放录音
[重录]             [完成回放]
```

### ViewModel 最低字段

- 活动类型：固定回答、引导角色扮演或业务模块定义的受控类型
- 对方话语、中文提示、示范答案的可见状态
- 麦克风权限展示状态
- 录音状态和时间标签
- 识别/有限匹配结果
- 录音是否可回放
- 降级说明、主行动和次行动

UI 不请求权限、不启动录音、不执行识别或文本匹配。

## 进度

### 页面任务

展示长期能力证据，避免把一天波动和连续天数包装成虚假成就。

```text
学习进度
三个专项分别看

词汇  当前 5.5  ↑ 改善
掌握 68% · 保持 61% · 置信度 72%

听力  当前 4.0  — 稳定
...

口语  证据不足
...

连续学习 5 天 / 最长 12 天
常见问题：细节遗漏、流利度

需要复测：听力、口语
[开始专项复测]
```

### 输入

- `ProgressSnapshot.domains`
- `ProgressSnapshot.streak`
- `ReassessmentRecommendation`

### 显示规则

- `levelChange` 必须保留正负方向，不能改写为百分比提升。
- `trend` 直接映射为改善、稳定、下降、证据不足。
- `commonErrors` 只展示业务模块已排序的结果。
- `confidence`、`recentPerformance`、`retentionScore`、`masteryScore` 只做格式化。
- 复测入口只在 `due === true` 时显示。
