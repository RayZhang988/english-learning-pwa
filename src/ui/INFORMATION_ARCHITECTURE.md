# 02｜界面信息架构与导航关系

本文只定义界面结构和状态呈现，不定义路由注册、评分、计划、训练判定或数据来源。
真实路由由 01 挂载，业务状态由对应模块通过 props 或 `ReadonlyDataSource<T>` 交给 UI。

## 一级结构

应用壳保留三个单手可达的底部入口：

| 一级入口 | 单一任务 | 主要内容 | 底部导航 |
| --- | --- | --- | --- |
| 今天 | 看清当天计划并自由选择任务 | 计划摘要、三个同级任务入口、推荐标记、计划警告 | 显示 |
| 训练 | 进入水平测试或指定专项 | 水平测试、词汇、听力、口语入口 | 显示 |
| 进度 | 理解三个专项的长期变化 | 专项趋势、连续学习、常见错误、复测建议 | 显示 |

训练开始后进入专注模式：隐藏底部导航，顶部只保留返回、当前专项和必要的阶段进度。
退出未完成训练时是否需要确认，由业务模块提供“是否已开始/可否直接退出”状态；UI
不自行推断。

## 页面清单

### 应用壳

1. **今天**
   - 新用户：没有能力档案，主行动是开始水平测试。
   - 已有档案、计划加载中：显示计划骨架。
   - `DailyPlan.status === ready`：显示完整计划。
   - `DailyPlan.status === partial`：显示已有任务和 `warnings`，不虚构补足时间。
   - `DailyPlan.status === empty`：解释当前没有可执行任务，展示业务模块提供的原因。
   - 同日未完成：按照 `PlanTaskAccess.tasks` 同时展示全部 `startable` 任务。
   - `recommendedTaskId` 只把对应任务标记为“建议先做”，不锁定其他入口。
   - 跨日结转：只展示 `carryOverTasks`，不把未开始任务冒充为已结转。

2. **训练**
   - 水平测试入口。
   - 词汇、听力、口语入口。
   - 未注册模块显示“尚未可用”，不可做成看似可点击但无结果的假入口。
   - 已注册模块可展示待完成任务数；数值必须由模块提供。

3. **进度**
   - 三个专项分别展示，不合并为虚假的总分。
   - 展示 `currentLevel`、`levelChange`、`trend`、`confidence` 和 `commonErrors`。
   - 展示 `streak.currentDays` 与 `streak.longestDays`。
   - `trend === insufficient-evidence` 时显示证据不足，不画上涨或下跌。
   - `ReassessmentRecommendation.due === true` 时显示专项复测入口和原因。

### 水平测试 `#/assessment`

1. 测试说明：15–20 分钟、三项独立估算、非官方认证说明。
2. 测试准备：音频检查、麦克风权限和录音降级说明。
3. 词汇阶段：选择题；支持未选择、已选择、提交中。
4. 听力阶段：播放限制、选择题、音频不可用状态。
5. 口语阶段：朗读、跟读、固定回答；支持录音、识别和回放降级。
6. 反馈：展示已记录、不可评分、跳过及录音回放/音频重试/设备检查降级提示。
7. 暂停：显示恢复或结束并保留部分结果；恢复目标由运行时决定。
8. 阶段切换：仅显示业务引擎给出的当前 `AssessmentPhase`。
9. 结果：
   - `estimated`
   - `low-confidence`
   - `unavailable`
   - `outcome === partial`
   - 必须展示档案 `disclaimer` 和 `warnings`

### 词汇 `#/vocabulary`

1. 任务说明。
2. 题目/复习卡。
3. 作答状态。
4. 判定反馈。
5. 单元完成。
6. 中断、跳过受限、内容故障。

具体题型状态与判定由 06 交付。02 只预留展示槽，不定义正确答案或表现分。

### 听力 `#/listening`

1. 任务说明。
2. 播放准备。
3. 首听/重复播放。
4. 理解检查。
5. 答后解释。
6. 单元完成。
7. 音频不可用、播放失败、离线资源缺失。

播放次数、速度、合成与降级由 07 交付。翻译仅在业务模块进入答后解释状态时显示。

### 口语 `#/speaking`

1. 任务说明。
2. 麦克风权限。
3. 录音待开始。
4. 录音中。
5. 识别处理中。
6. 结果反馈。
7. 识别不可用时录音回放降级。
8. 单元完成。

权限、录音、识别、匹配和降级状态由 08 交付。02 不调用设备 API。

## 导航关系

```text
启动
 └─ 今天
     ├─ 无能力档案 ─────────────→ 水平测试
     ├─ 任选未完成任务 ── taskId 意图 ─→ 01 注入的对应专项训练
     └─ 底部导航
         ├─ 今天
         ├─ 训练
         │   ├─ 水平测试 ───────→ #/assessment
         │   ├─ 词汇 ───────────→ #/vocabulary
         │   ├─ 听力 ───────────→ #/listening
         │   └─ 口语 ───────────→ #/speaking
         └─ 进度
             └─ 到期复测 ───────→ #/assessment

专项训练完成
 ├─ 还有未完成项 ───────────────→ 今天（仍可自由选择）
 └─ 今日任务结束 ───────────────→ 今天
```

业务模块路由属于 01/03/06/07/08。02 导出的按钮只触发回调或链接意图，不直接注册路由。
今天页和训练页的可执行任务卡只回传 `DailyTaskViewModel.taskId`；可用性必须直接来自
`PlanTaskAccess.tasks[].availability`。`recommendedTaskId` 只映射推荐视觉，UI 不根据
推荐、模块顺序、数组位置或前一任务状态推导权限。

## 通用状态矩阵

| 状态来源 | UI 必须支持 | UI 禁止推断 |
| --- | --- | --- |
| `AsyncDataState<T>` | idle、loading、empty、ready、error | 何时切换状态 |
| 网络 | online、offline | 离线资源是否真的已安装 |
| PWA 生命周期 | offline-ready、update-available、registration-error | 自动应用更新 |
| 每日计划 | ready、partial、empty | 补足分钟、重排任务 |
| 任务执行 | pending、active、paused、completed、skipped、blocked | 跳过许可和完成条件 |
| 测试专项 | collecting、stopped、unavailable | 停止原因和评分 |
| 能力估计 | estimated、low-confidence、unavailable | 用其他专项补全缺失值 |
| 进度趋势 | improving、stable、declining、insufficient-evidence | 重新计算趋势 |
| 麦克风 | granted、denied、prompt、unsupported、unknown | 主动请求权限 |
| 训练故障 | device、permission、network、content、interrupted | 把故障算成学习失败 |

## 导航与可访问性约束

- 底部导航固定为 3 项，避免 iPhone 单手区拥挤。
- 训练流隐藏底部导航，防止误触中断。
- 所有可点击区域至少 `44 × 44px`。
- 页面标题使用唯一 `h1`，专项阶段和题目用 `h2`。
- 当前导航使用 `aria-current="page"`；阶段进度使用原生或等价的进度语义。
- 音频、录音和动态反馈不能只靠颜色；必须有文本、图标和可读状态。
- 返回操作名称必须指向实际目的地，例如“返回今日计划”，不能只写“返回”。

## 尚待业务模块交付

- 06：词汇题型、作答、判定和反馈状态清单。
- 07：播放器、播放限制、题型和音频降级状态清单。
- 08：权限、录音、识别、有限匹配和回放降级状态清单。

这些缺口不阻塞应用壳、水平测试、每日计划、进度和通用状态的设计，但会阻塞三个专项
训练页面的最终验收。
