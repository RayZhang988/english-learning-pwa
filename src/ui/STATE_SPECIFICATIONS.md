# 02｜系统状态与降级界面

## 统一结构

每个非正常状态必须回答三个问题：

1. 发生了什么。
2. 哪些内容仍然可用。
3. 用户现在能做什么。

状态组件只显示外部传入的事实和触发回调，不检测网络、权限、缓存或设备能力。

## 异步数据

| `AsyncDataState` | 呈现 | 主行动 |
| --- | --- | --- |
| `idle` | 默认不占据整页；需要明确启动时显示说明 | 由模块提供 |
| `loading` | 保留最终布局的骨架，标题保持可见 | 无 |
| `empty` | 说明为什么为空和下一步 | 由模块提供 |
| `ready` | 正常内容 | 正常页面行动 |
| `error` | 错误标题、可读说明、重试或返回 | 重试或返回 |

规则：

- 加载超过业务模块定义的阈值后是否显示慢速提示，由外部状态决定。
- 骨架不模拟无法预测的长文本；最多保留标题、主卡和 2–3 行结构。
- 重试按钮触发回调，UI 不自己重新加载数据。

## 每日计划

### 无能力档案

- 标题：`先找到适合你的起点`
- 说明：`完成一次 15–20 分钟的水平测试，才能安排词汇、听力和口语任务。`
- 主行动：`开始水平测试`

### `DailyPlan.status === empty`

- 标题：`今天还没有可执行任务`
- 说明：使用业务模块提供的 `warnings` 或空状态原因。
- 不显示 `0%`、`0 / 0` 或假任务。

### `DailyPlan.status === partial`

- 顶部计划卡正常显示 `plannedSeconds`。
- 明确显示 `unfilledSeconds`，文案为“仍有 X 分钟未排入内容”。
- `warnings` 原样显示，不自行补充任务。

### 任务 `blocked`

- 不使用错误红色，除非业务模块明确给出不可恢复错误。
- 显示“当前任务暂时无法继续”和模块提供的原因。
- 若有可用下一项，由业务模块提供对应行动。

## 离线

### 应用已离线、当前内容可用

- 使用紧凑顶部横幅，不打断训练。
- 标题：`当前处于离线状态`
- 说明：`已下载的词汇和听力内容仍可使用。`

### 内容未下载

- 使用页面内状态卡。
- 标题：`这项内容尚未下载`
- 说明：`连接网络并完成下载后，才能离线使用。`
- 主行动：`连接网络后重试`

不能仅凭 `navigator.onLine` 宣称内容可用；必须同时消费离线资源状态。

## PWA 生命周期

### 可离线使用

- 轻量提示：`已准备好离线使用`
- 自动消失或关闭由 01 的 PWA 状态控制。

### 有新版本

- 标题：`有新版本可用`
- 说明：`更新会重新加载应用，当前训练请先完成或暂停。`
- 主行动：`立即更新`
- 次行动：`稍后`

UI 不自动调用更新。

### 注册失败

- 标题：`离线功能暂时不可用`
- 说明：使用 01 映射后的可读错误。
- 不阻止在线学习。

## 麦克风权限

| 状态 | 标题 | 说明 | 行动 |
| --- | --- | --- | --- |
| `prompt` | 需要麦克风权限 | 录音仅保存在当前设备，用于口语任务和回放 | 允许麦克风 |
| `denied` | 麦克风权限已关闭 | 请在 Safari 网站设置中允许麦克风，然后返回重试 | 查看设置说明 / 重试 |
| `unsupported` | 当前浏览器无法录音 | 可跳过口语或使用支持录音的 Safari | 返回今日计划 |
| `unknown` | 尚未确认麦克风状态 | 开始录音时系统可能询问权限 | 检查麦克风 |
| `granted` | 不显示权限状态卡 | 进入录音准备 | 无 |

“录音仅保存在当前设备”只有在 08 确认实现符合该事实后才能显示；02 提供文案槽位，
不硬编码隐私承诺。

## 录音与识别降级

### 未检测到语音

- 标题：`没有检测到清晰语音`
- 行动：`重新录音`
- 若录音可用，提供 `播放录音`。

### 识别不可用或失败

- 标题：`本次无法识别`
- 说明：`这次不会评分，你仍可以播放录音检查表达。`
- 主行动：`播放录音`
- 次行动：`重新录音`

### 离线导致识别不可用

- 标题：`离线时无法识别口语`
- 说明：`录音和回放仍可使用，本次不会评分。`

### 录音失败

- 标题：`录音没有保存成功`
- 说明：使用 08 映射后的原因。
- 不能显示回放按钮。

所有 `unscorable` 状态禁止使用“错误答案”“能力下降”或负向分数。

## 正式水平测试运行状态

### 本题已记录

- 展示适配层提供的中性反馈。
- 主行动为 `继续下一题`，触发独立 `onContinue`。
- 不显示仍可触发的提交或跳过行动。

### 主动跳过

- `lastSubmission.status === skipped` 时明确显示“本题已跳过”。
- 选择题是否计零分、口语是否不可评分由 03 决定；UI 不解释评分结果。
- 主行动为 `继续下一题`。

### 识别或音频失败

- 保留 `lastSubmission.itemId`、`failureReason` 和 fallback 种类。
- `recording-playback`：说明录音仍可回放。
- `retry-audio`：说明音频可检查或重试，但 UI 不自行重播。
- `device-check`：说明需要检查设备或权限。
- 所有中文标题、说明和行动可用性由集成层传入，UI 不从错误码硬编码业务处理。

### 暂停

- 使用 assessment 专用暂停页，不复用通用错误页。
- `onResume(sessionId)` 和 `onStop(sessionId)` 原样回传正式会话 ID。
- 恢复后回到答题还是反馈由 03 snapshot 的 `resumeTo` 决定，UI 不读取或推断。
- 03 没有 restart 动作，因此不显示“重新开始”。

## 音频故障

### 音频不可用

- 标题：`这段音频暂时无法播放`
- 说明：区分资源未下载、系统播放失败和内容损坏。
- 主行动由 07 提供：重试、下载或返回。

### 播放中断

- 保留已播进度，但是否允许续播由 07 决定。
- 不自动把播放中断算成尝试完成。

## 水平测试部分结果

### `low-confidence`

- 显示估计等级、区间和“证据有限”。
- 保留 `warnings`。
- 不隐藏结果，也不把它包装成确定结论。

### `unavailable`

- 标题：`暂无可靠结果`
- 显示业务 `message` 和警告。
- 不显示 0、pre-A1 或灰色空进度条。

### `outcome === partial`

- 已可靠的专项正常展示。
- 缺失专项独立显示不可用状态。
- 页面整体标题使用“部分结果”，不能写“测试失败”。

## 进度证据不足

- `trend === insufficient-evidence`：文字显示“证据不足”，图表不画趋势箭头。
- `commonErrors.length === 0`：隐藏整个常见问题区，不显示“你没有错误”。
- `confidence` 较低时只显示业务字段，不自行建议降级或增加训练。

## 视觉语义

| 类型 | 图标/色彩 | 语气 |
| --- | --- | --- |
| 成功完成 | 勾选、mint | 陈述结果 |
| 普通提醒 | 信息图标、indigo | 提供下一步 |
| 设备/网络降级 | 设备图标、coral | 中性、不责备 |
| 可恢复错误 | 感叹号、danger | 说明重试 |
| 不可用/证据不足 | 空心标记、中性色 | 如实说明缺失 |

状态不能只靠颜色区分，必须同时使用标题、说明和图标。
