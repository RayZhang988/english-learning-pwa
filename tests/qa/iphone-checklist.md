## 3. 三类训练与刷新恢复

### 听力

- [ ] 依次选择 `0.75×`、`1×`、`1.25×`，只有整体速度变化，没有额外隐藏变速或变调。
- [ ] 用户选择某一句后，只朗读该句正文；返回完整场景后重新朗读连续整段。
- [ ] 暂停、恢复、取消、重复当前、循环全部和调速后仍能正常工作。

## 4. 离线与缓存

先在线完整打开过首页、首日计划、当天词汇和听力内容。然后：

1. 完全关闭 App。
2. 开启飞行模式，并确认 Wi‑Fi 已关闭。
3. 从主屏幕图标重新打开。

- [ ] 离线时应用壳能启动，不是 Safari 网络错误白页。
- [ ] 离线时当天已安装的词汇内容可进入和使用。
- [ ] 离线时当天已安装的听力文本可进入。
- [ ] 若本机已有 `en-US` 系统语音，听力能播放；若没有，页面明确说明设备限制，
  不把失败算成答错。实际结果：
- [ ] 离线完成的进度在恢复网络、关闭再开后仍保留。
- [ ] 离线状态有清楚提示，不声称已联网或已同步云端。

完成后关闭飞行模式并恢复网络。

## 5. 麦克风、识别失败与录音回放降级

### 先拒绝权限

1. 进入首日口语任务。
2. 第一次请求麦克风时点“不允许”。

- [ ] 拒绝后页面没有卡死或崩溃。
- [ ] 页面明确说明无法录音，并允许“不评分继续”或等价降级。
- [ ] 系统没有把权限拒绝、无录音或无识别结果记成答错。

### 再允许并验证回放

1. 在 Safari 地址栏的页面菜单中打开“网站设置”，把麦克风改为“允许”；
   若系统没有此入口，到“设置 → App → Safari → 麦克风”改为“询问”后重试。
2. 录一段 3–5 秒语音，停止并播放。

- [ ] 能开始录音、停止录音并听到自己的录音。
- [ ] 录音中切到主屏幕再返回时，页面能安全停止或明确恢复，不会假装仍在录。

### 制造识别不可用

1. 保留已录好的语音。
2. 开启飞行模式并关闭 Wi‑Fi，再尝试识别或提交。

- [ ] 识别不可用时仍能播放刚才的本地录音。
- [ ] 页面明确显示识别失败/不可用，没有伪造识别文本。
- [ ] 没有因识别失败压低口语等级、掌握度或计划进度。
- [ ] 可以选择不评分继续，不会阻断当天学习。

恢复网络后关闭并重新打开 App：

- [ ] 旧录音没有被伪装成仍可回放；学习进度仍保留。
- [ ] 没有看到登录、云同步、付费服务或录音上传提示。

证据：权限拒绝、允许录音、离线识别失败三个阶段各保存截图或短录屏。
