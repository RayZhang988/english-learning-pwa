# 09｜第一版测试策略与质量门槛

## 1. 结论规则

第一版只能在以下条件全部满足后判定“通过”：

1. `pnpm check` 在待验收提交上可复现通过。
2. 需求—测试追踪表中所有 `MUST` 项都有真实、可重复的通过证据。
3. 当前活动需求 R1 必须从全新数据进入旅游英语分阶段单词测试，完成 5×30 题后产生
   schema 3 `AbilityProfile`：词汇为估算结果，听力和口语诚实保持待校准，并生成真实
   首日计划。旧 v1/v2、演示数据或视觉夹具不能替代。
4. 首日计划中的词汇、听力、口语任务均通过计划内真实 `taskId` 启动；禁止用
   `demoPlan`、视觉夹具或手工构造任务代替。
5. PWA 安装资源、离线应用壳、缓存更新、进度保存、刷新恢复和故障降级通过。
6. 真实 iPhone Safari 与主屏幕 Web App 检查通过。
7. 连续 14 天个人使用没有阻断性缺陷，且每天都有可核对记录。
8. 未关闭缺陷中，S0、S1、影响 `MUST` 门槛的 S2 数量均为 0。
9. 听力系统语音在真实 iPhone/用户听感中自然、清晰、连贯；voice 数量、voiceId、
   pitch 或 rate 参数不同不能替代真实听感证据。
10. 单项需求串行门禁生效：R1 的自动化、正式站、旧数据恢复和真实 iPhone 入口未全部
    验收前，不得开始训练顺序、时长、继续训练、听力题面、口语匹配或任务得分等排队
    需求。

自动化通过不等于第一版通过。真实 iPhone、系统权限、设备语音自然度、后台中断和
连续 14 天使用没有真实证据时，最终结论只能是“未完成验收”，不能推断为通过。

## 2. 测试层次

| 层次 | 目的 | 主要证据 |
| --- | --- | --- |
| 静态交付审计 | 确认文件、公开契约、内容包和 PWA 产物存在 | 文件清单、Schema/契约检查 |
| 现有项目门禁 | 复现各所有者已有的单元与集成验证 | `pnpm check` 原始结果 |
| QA 集成测试 | 从公开入口验证评估、档案、计划、任务和存储衔接 | `tests/qa/**` |
| 浏览器端到端 | 从空浏览器状态验证真实用户链路、恢复和响应式行为 | `tests/e2e/**` |
| 正式站冒烟 | 验证发布版本、Manifest、Service Worker 和静态资源 | HTTPS 响应与浏览器证据 |
| 真机验收 | 验证 iPhone Safari/PWA、权限、系统音频、后台和离线 | 勾选清单、截图/录屏、备注 |
| 14 天实测 | 验证个人长期使用无阻断和数据丢失 | 每日记录表、缺陷记录 |

## 3. 缺陷严重程度

| 等级 | 定义 | 典型示例 | 验收处理 |
| --- | --- | --- | --- |
| S0 致命 | 数据不可恢复丢失、隐私边界被突破、存在未经授权的数据上传 | 清除范围错误导致其他本地数据丢失；录音被上传 | 立即不通过，交回所有者 |
| S1 阻断 | 核心链路无法继续且没有可接受降级 | 无法启动/完成评估；不生成计划；三个训练模块之一完全无法进入；刷新后记录消失 | 立即不通过，修复后全链路回归 |
| S2 严重 | 核心能力明显错误，但仍有绕行或仅部分场景受影响 | 离线内容不可用；识别失败被记错；听力语音机械到影响训练；PWA 更新卡死 | 影响 `MUST` 时不通过，修复后专项加回归 |
| S3 一般 | 不阻断学习的局部可用性、文案或视觉问题 | 次要窄屏溢出；非关键焦点顺序不佳 | 可带风险记录，但不得掩盖为通过 |

缺陷报告必须包含：环境、版本/提交、前置条件、最短复现步骤、实际结果、期望结果、
影响、严重程度、证据位置、建议责任任务和回归范围。09 不修改生产代码。

## 4. 质量门槛

| 门槛 | 必须满足的条件 |
| --- | --- |
| G0 可构建 | lint、类型检查、全部现有测试、生产构建、PWA 生成全部通过 |
| G1 首次使用 | 空数据只进入 R1；5 阶段各 30 个旅游英语单词；不显示目标/最长时长；输出估算词汇量、区间、15 级内部标签，听力/口语待校准；生成 schema 3 档案与首日计划 |
| G2 训练衔接 | 计划内真实 `taskId` 分别进入词汇、听力、口语；事件更新进度；返回首页后状态一致 |
| G3 数据韧性 | 评估中断、训练中断、刷新、关闭再开均按契约恢复；重复事件不重复计数；损坏/未来版本不被静默覆盖 |
| G4 PWA/离线 | Manifest、图标、SW、HTTPS 正常；应用壳离线可开；已安装词汇和听力资源离线可用；更新有明确状态 |
| G5 设备与语音 | 权限拒绝、离线、识别失败、合成/录音失败均诚实降级；系统语音自然、清晰、连贯；无听感验证时使用中性默认 voice，不伪造人物差异 |
| G6 兼容与无障碍 | iPhone 常见窄屏无阻断溢出；键盘可操作；焦点、标签、语言和状态提示可理解 |
| G7 内容完整 | 4 周、28 天、84 单元及引用/答案/前置链符合 05 交接基线，无占位内容 |
| G8 真机稳定 | Safari 与主屏幕安装、权限、离线、后台、恢复通过；连续 14 天无 S0/S1 |
| G9 R1 串行门禁 | R1 自动化、正式站、旧数据迁移/损坏恢复和真实 iPhone 入口全部通过；此前不得推进任何排队需求 |

任何门槛未验证都不是“默认通过”。门槛状态只允许：

- `通过`：已有真实证据且可复现；
- `自动化通过`：无需设备的契约、数据或静态产物已通过，但不能替代浏览器/真机；
- `浏览器未测`：浏览器控制环境不可用或本轮明确禁止启动浏览器；
- `不通过`：已复现失败；
- `待真机`：只能由真实 iPhone/系统环境验证；
- `待实测`：需要跨日或连续 14 天；
- `被阻塞`：存在具体缺失文件、失败测试或不兼容契约。

## 5. 环境矩阵

| 环境 | 用途 | 最低覆盖 |
| --- | --- | --- |
| 本地生产预览 | 可控数据、自动化、离线和恢复 | Chromium 桌面、iPhone 窄屏模拟 |
| GitHub Pages 正式站 | 发布与缓存冒烟 | HTTPS、Manifest、SW、首屏、静态课程资源 |
| iPhone Safari | 浏览器真机 | 全新网站数据、权限允许/拒绝、刷新、离线 |
| iPhone 主屏幕 Web App | 安装态真机 | 启动、离线、后台恢复、更新、存储保留 |

桌面浏览器模拟不能替代 Safari 的系统语音、麦克风、MediaRecorder、主屏幕安装、
后台回收和存储清理行为。
