# 05｜首批课程包说明

## 交付定位

首批课程采用 4 周、28 个顺序内容块，覆盖日常生存沟通和一次完整旅行链路。内容不是
“按日强制播放”的固定计划：04 根据用户三个专项的能力、复习积压和当天可用时间，
从当前已解锁的学习单元中生成计划。本文中的“第 N 天”只表示推荐解锁顺序。

课程 ID：`survival-travel-american-4w`

- 内容包版本：`1.0.0`
- 内容格式版本：`1`
- 目标语言：英语（美国），`en-US`
- 解释语言：简体中文，`zh-CN`
- 难度覆盖：内部等级 `0.5–5.5`，约从 pre-A1/A1 到 B1
- 核心受众：需要建立日常与旅行生存沟通能力的中文母语成人
- 明确限制：这不是完整 CEFR 课程，也不为 B2–C2 用户伪造足量进阶内容

## 课程完成目标

完成首批课程并通过场景检查后，学习者应能：

1. 用简短、礼貌、可理解的美式英语完成自我介绍并交换基本信息。
2. 听懂并表达常见数字、价格、时间、日期和简单行程。
3. 在餐厅、商店、酒店、机场和本地交通场景完成固定意图沟通。
4. 提出基本需求、确认关键信息、请求重复或澄清。
5. 在轻微差错、身体不适、物品丢失等低复杂度场景中求助。
6. 把已学句型迁移到连续的“抵达—住宿—出行—消费—返程”旅行任务。

目标是“能完成任务”，不是“像母语者一样自然”。首批内容不承诺开放式对话、专业
发音评分、复杂投诉、医疗诊断、法律沟通或高阶社交。

## 每个内容块的供给负荷

每个内容块提供三个可独立调度的学习单元：

| 专项 | 建议内容时长 | 内容构成 |
| --- | ---: | --- |
| 词汇 | 900 秒 | 5–7 个核心词/短语、搭配、例句和受控检查 |
| 听力 | 900 秒 | 原创短对话或播报、场景理解、辨音、短句听辨和关键词听写 |
| 口语 | 900 秒 | 固定问答、可接受回答、替换槽和场景挑战 |
| 合计 | 2700 秒 | 作为 04 生成约 45 分钟计划时的候选内容供给 |

`estimatedSeconds` 是内容事实，不是用户必须用满的计时器。复习、重试和续学由 04
优先调度，因此实际某天可能只使用其中一部分新内容。

核心课程入口仍为 `content/curriculum/package-index.v1.json`。为保持既有消费者和
`contentRef` 稳定，三类新增听力题型通过独立入口
`content/curriculum/listening-exercise-extension-index.v1.json` 交付；07/09 的详细
消费与验收规则见 `content/curriculum/listening-exercise-handoff-v1.md`。

## 难度与解锁原则

1. 难度使用 03/04 的内部 `0–12` 标尺，不把课程包自己的标签冒充官方 CEFR。
2. 三个专项分别标级；同一场景的听力可以比词汇难，因为连续语流增加了负担。
3. 下一内容块只依赖前一内容块同专项的核心单元，避免一个专项卡住全部课程。
4. 第 7、14、21、28 天不引入大批新词，主要复用此前语言完成综合任务。
5. 内部等级高于 `5.5` 的用户仍可使用这些场景内容补缺，但第一版不会假装提供
   B2–C2 难度覆盖；04 应如实报告候选内容与目标难度的差距。

## 标准美式与版权原则

- 拼写、词义和场景措辞统一采用常见美式用法，例如 `restroom`、`check`、
  `takeout`、`round trip`、`ZIP code`。
- 避免把地区性很强或容易失礼的表达当作唯一正确答案。
- 酒店、机场、餐厅等场景中的专有名词均为虚构，不复制真实企业话术。
- 所有例句、对话、题目和固定口语任务均为本项目原创受控文本，不摘录教材、
  影视字幕、考试真题、歌词或旅游网站文案。
- 后续多口音扩展只允许增加发音与听力变体，不得悄悄改变词义、答案或难度标尺。
